# Fix 001: Missing Database Columns

## Issue
Multiple tests failing due to missing database columns:
- `price_offers` table missing `description` and `status` columns
- `price_histories` table missing `recorded_at`, `currency`, and `old_price` columns  
- `users` table missing `banned_by`, `unbanned_at`, `unbanned_by` columns

## Root Cause
Database migrations did not include all columns expected by the models and service code. Test database setup also lacked these columns.

## Fix Applied
1. Created migration `2025_11_29_000001_add_missing_test_columns.php` to add missing columns
2. Updated `tests/DatabaseSetup.php` to include missing columns in table creation methods
3. Added `createPriceHistoriesTable` method to test database setup

## Files Changed
- `database/migrations/2025_11_29_000001_add_missing_test_columns.php` (new)
- `tests/DatabaseSetup.php`
