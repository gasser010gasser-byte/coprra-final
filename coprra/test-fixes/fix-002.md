# Fix 002: Category Level Calculation Not Persisting

## Issue
Category level calculation tests failing because level is not being persisted:
- `CategoryTest::testSlugAndLevelAutoGeneratedOnCreating` - Expected level 0, got null
- `CategoryTest::testLevelBasedOnParentOnCreating` - Expected level 2, got null
- `CategoryTest::testLevelUpdatedOnParentChange` - Expected level 2, got null

## Root Cause
The `calculateLevel()` method in Category model was setting `$this->level` property but not setting it in the `attributes` array. During the creating/updating events, attributes that are only set as properties may not be persisted to the database. Additionally, `parent_id` was being accessed directly instead of from the attributes array.

## Fix Applied
1. Modified `calculateLevel()` to set level in both `$this->attributes['level']` and `$this->level` property
2. Updated `handleCreatingEvent()` to check `parent_id` and `level` from attributes array
3. Updated `calculateLevel()` to read `parent_id` from attributes array
