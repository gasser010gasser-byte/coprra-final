# Fix 003: Model Slug Generation and Price History

## Issues
- Store, Category, Brand models - slug not being generated on create/update
- PriceHistoryAccuracyTest - price history records not being created or detected

## Root Cause
1. Slug generation logic existed but may not have been executing correctly during creation
2. PriceHistory model didn't specify table name, causing potential table name mismatch
3. Test needed to explicitly reload relationship after updates

## Fix Applied
1. **Slug Generation:**
   - Updated Store, Category, Brand models to ensure slug is generated when name is provided and slug is empty
   - Added empty check for expectedSlug before setting
   - Improved attribute synchronization

2. **Price History:**
   - Added explicit table name 'price_history' to PriceHistory model
   - Updated test to explicitly reload relationship after updates
   - Added null checks in test assertions

## Files Changed
- `app/Models/Store.php`
- `app/Models/Category.php`
- `app/Models/Brand.php`
- `app/Models/PriceHistory.php`
- `tests/Unit/DataAccuracy/PriceHistoryAccuracyTest.php`
