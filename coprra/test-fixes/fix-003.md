# Fix 003: Slug Generation Issues in Models

## Issue
Tests failing because slugs were null in Store, Category, and Brand models when created via `Model::create()`.

## Root Cause
The `generateSlug()` method accessed `$this->name` property, but during model event firing, the name attribute might not be accessible via property access. Need to access via `$this->attributes['name']` as fallback.

## Fix Applied
Updated `generateSlug()` methods in Store, Category, and Brand models to access name from both attributes array and property, and explicitly set both `$this->slug` and `$this->attributes['slug']`.

## Files Changed
- `app/Models/Store.php`
- `app/Models/Category.php`
- `app/Models/Brand.php`
