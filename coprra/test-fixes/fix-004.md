# Fix #004: Slug Generation Improvements for Store, Brand, and Category Models

## Issues Addressed
- Store, Brand, and Category models not generating slugs automatically in tests
- Inconsistent slug generation logic across models

## Root Cause Analysis
The slug generation methods in Store, Brand, and Category models had logic that might fail in certain edge cases:
1. Checking `$this->slug` property before checking `$this->attributes['slug']`
2. Not properly validating that name is a string
3. Potential race conditions with attribute access

## Fix Applied

### Files Changed:
1. `app/Models/Store.php` - Improved generateSlug() method
2. `app/Models/Brand.php` - Improved generateSlug() method  
3. `app/Models/Category.php` - Improved generateSlug() method

### Code Changes:
All three models now use improved slug generation logic that:
- Validates name is a non-empty string
- Checks both attributes array and property for current slug value
- Sets slug in both attributes array and property for consistency
- Ensures slug is always generated when name is provided and slug is empty/dirty
