# Fix 004: Slug Generation Issues in Category, Store, and Brand Models

## Issue Excerpt
```
17) Tests\Unit\Models\CategoryTest::testSlugAndLevelAutoGeneratedOnCreating
Failed asserting that null is identical to 'test-category'.

21) Tests\Unit\Models\StoreTest::testSlugAutoGeneratedOnCreating
Failed asserting that null is identical to 'test-store'.

23) Tests\Unit\Models\BrandTest::testSlugAutoGeneratedOnCreating
Failed asserting that null is identical to 'test-brand'.
```

## Root Cause Analysis
The slug generation logic in Category, Store, and Brand models was accessing attributes directly via `$this->attributes['name']`, which may not work correctly during model events. The `getAttribute()` method provides more reliable access to model attributes, especially during creating/updating events.

## Fix Applied
Updated slug generation methods in all three models to:
1. Use `getAttribute()` as the primary method for accessing attributes
2. Added `setAttribute()` call to ensure slug is properly set
3. Improved empty check to handle both null and empty string cases
