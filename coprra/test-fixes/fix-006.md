# Fix 006: Store Model Slug Generation

## Issue
```
Tests\Unit\StoreModelTest::testSlugGenerationOnCreate
Failed asserting that null is identical to 'test-store-name'.
```

## Root Cause
The Store model's generateSlug() method had complex logic checking `$this->exists` which might not work correctly during the creating event.

## Fix Applied
Simplified the generateSlug() method to always set slug when name is provided and slug is null/empty or doesn't match expected slug, similar to Category and Brand models.

## Files Changed
- `app/Models/Store.php` - Simplified generateSlug() method logic

## Tests Fixed
- Tests\Unit\StoreModelTest::testSlugGenerationOnCreate
- Tests\Unit\Models\StoreTest::testSlugAutoGeneratedOnCreating
- Tests\Unit\Models\StoreTest::testSlugUpdatedOnNameChange
