# Fix 008: AnalyticsService Unicode Metadata with Null Bytes

## Issue
Test `AnalyticsServiceEdgeCaseTest::testTrackWithUnicodeMetadata` failing because metadata containing null bytes cannot be stored in JSON format, causing the track method to return null.

## Root Cause
JSON encoding does not support null bytes (`\0`). When metadata contains null bytes, the database insert fails silently and the method returns null. The test was expecting the exact metadata array to be returned, but JSON storage requires sanitization.

## Fix Applied
1. Added `sanitizeMetadata()` method to `AnalyticsService` that recursively removes null bytes from all string values in the metadata array
2. Updated the `track()` method to sanitize metadata before storing
3. Updated the test to expect sanitized metadata (null bytes removed) while preserving all other unicode characters

## Files Changed
- `app/Services/AnalyticsService.php` - Added sanitizeMetadata method and applied it in track method
- `tests/Unit/Services/AnalyticsServiceEdgeCaseTest.php` - Updated test expectation to match sanitized metadata
