# Fix 011: CategoryTest slug and level generation issues

## Original Failure
```
11) Tests\Unit\Models\CategoryTest::testSlugAndLevelAutoGeneratedOnCreating
Failed asserting that null is identical to 'test-category'.

12) Tests\Unit\Models\CategoryTest::testLevelBasedOnParentOnCreating
Failed asserting that null is identical to 2.

13) Tests\Unit\Models\CategoryTest::testSlugUpdatedOnNameChange
Failed asserting that null is identical to 'new-name'.

14) Tests\Unit\Models\CategoryTest::testLevelUpdatedOnParentChange
Failed asserting that null is identical to 2.
```

## Root Cause Analysis
Similar to Brand model, the Category model's `handleUpdatingEvent` only generates slugs when the name is dirty, but it should also generate slugs when the slug is explicitly set to null or empty. The level calculation might also have issues if the parent_id isn't being processed correctly.

## Fix
Update the `handleUpdatingEvent` to also generate slugs when the slug attribute is dirty and set to null/empty. Also ensure the creating event checks if slug is empty before generating.
