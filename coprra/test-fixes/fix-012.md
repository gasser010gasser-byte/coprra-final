# Fix 012: PriceOffer Model Missing Fields and Alternative Products Filtering

## Issues
1. `APIIntegrationTest::testPriceSearchByProductIdWithComprehensiveOfferData` - Expected 25.0 (float), got 25 (int) for shipping_cost
2. `APIIntegrationTest::testPriceSearchByProductNameWithFuzzyMatching` - Array contains unrelated product (id 3) that should be excluded

## Root Causes
1. shipping_cost and delivery_time columns exist in database (via migration) but were not in PriceOffer model's fillable array or casts, causing type issues
2. Alternative products filtering only checked category_id, not brand_id, so unrelated products from same category were included

## Fixes Applied
1. Added shipping_cost and delivery_time to PriceOffer model's fillable array
2. Added shipping_cost to casts as 'decimal:2' to ensure proper float type
3. Improved alternative products filtering to:
   - Filter by brand_id when available (same brand = more relevant)
   - Calculate similarity score based on brand match and name word overlap
   - Limit to 3 most relevant products

## Files Changed
- `app/Models/PriceOffer.php` - Added shipping_cost and delivery_time to fillable and casts
- `app/Http/Controllers/Api/PriceSearchController.php` - Improved alternative products filtering logic
