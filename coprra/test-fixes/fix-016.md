# Fix 016: StoreModelTest slug generation issues

## Original Failure
```
22) Tests\Unit\StoreModelTest::testSlugGenerationOnCreate
Failed asserting that null is identical to 'test-store-name'.

36) Tests\Unit\Models\StoreTest::testSlugAutoGeneratedOnCreating
Failed asserting that null is identical to 'test-store'.

37) Tests\Unit\Models\StoreTest::testSlugUpdatedOnNameChange
Failed asserting that null is identical to 'new-name'.
```

## Root Cause Analysis
Similar to Brand and Category models, the Store model's `updating` event only generates slugs when the name is dirty, but it should also generate slugs when the slug is explicitly set to null or empty.

## Fix
Update the `updating` event to also generate slugs when the slug attribute is dirty and set to null/empty. Also ensure the creating event checks if slug is empty before generating.
