### Fix 009, 011, 016: Brand, Category, and Store slug auto-generation
**Commit:** f5d2130b  
**Files Changed:**
- `app/Models/Brand.php`
- `app/Models/Category.php`
- `app/Models/Store.php`
- `coprra/test-fixes/fix-009.md`
- `coprra/test-fixes/fix-011.md`
- `coprra/test-fixes/fix-016.md`

**Root Cause:** 
- `creating` events were generating slugs even when slug was already set
- `updating` events only generated slugs when name was dirty, not when slug was explicitly set to null

**Fix:**
- Updated `creating` events to only generate slug if slug is empty
- Updated `updating` events to also generate slug when slug attribute is dirty and set to null/empty, not just when name is dirty
